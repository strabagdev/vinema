# Roadmap

## Implementado

- Behavioral Engine v1: observación determinista de patrones recurrentes,
  emergentes, decrecientes, estables y clusters pequeños.
- VIN-014F Semantic Understanding v1: detección determinista de relaciones
  semánticas explícitas con evidencia, confianza y contradicciones básicas.
- VIN-014G Memory Evolution v1: señales temporales derivadas para conceptos
  nuevos, crecientes, estables, decrecientes, dormidos, reactivados y con cambio
  de contexto.
- VIN-014H Knowledge Suggestions v1: sugerencias locales y deterministas de
  conocimiento existente mientras el usuario escribe, agrupadas como
  relacionado ahora, podría faltar y retomar.
- VIN-014I Memory Orchestrator v1: API cognitiva pública que coordina perfiles,
  relaciones, patrones, significados, evolución y sugerencias en una respuesta
  única con summary y evidencia deduplicada.

## Próximas iteraciones cognitivas

- explicar evidencia sin interpretar significado;
- decidir cuándo una señal merece aparecer en la superficie principal;
- explorar patrones longitudinales por concepto;
- evaluar visualizaciones mínimas sin introducir complejidad de grafo.
- relaciones implícitas;
- tipos emergentes;
- inferencia semántica;
- razonamiento multi-captura;
- preguntas sobre la memoria.
- evolución de relaciones;
- ciclos estacionales;
- tendencias de largo plazo;
- olvido asistido;
- refinamiento de sugerencias basadas en evolución.
